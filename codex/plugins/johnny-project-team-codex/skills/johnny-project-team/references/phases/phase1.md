# Phase 1: Architectural frame

Architect converts the approved intent into the frame that constrains later work.

## Required outcomes

- System context and boundaries
- Core components and responsibilities
- External interfaces and trust boundaries
- Primary data flow
- Architecture decisions with rationale
- Known constraints and viable implementation freedoms

Specify enough structure to prevent incompatible construction. Do not prescribe
internal classes, naming, or speculative abstractions. Produce architecture and ADR
artifacts, then advance only after explicit user approval.
