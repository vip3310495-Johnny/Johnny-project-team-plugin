# Phase 6: Scope-quality retrospective

Review how well the contract guided construction.

## Review questions

- Which FIXED items were unnecessarily prescriptive?
- Which items were too broad to preserve user intent?
- Which classifications were challenged or changed?
- Which compatibility failures or undocumented changes occurred?
- What template or heuristic should improve the next project?

Record Lessons Learned and separate Contract Violations from
Process/Documentation Defects. Do not rewrite Phase 5 history; propose improvements
for future work instead. Close active child agents and archive the project state.
