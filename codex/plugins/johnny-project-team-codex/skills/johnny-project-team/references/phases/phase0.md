# Phase 0: Intent discovery

PM and the user establish why the project exists before choosing implementation.

## Required outcomes

- Intent and target user
- Observable business outcome
- Non-goals and scope boundary
- Major risks and unknowns
- Initial acceptance examples

Use `5w1h-grill-me` when the request is ambiguous. Do not involve DQA in implementation
review and do not freeze technical details that Phase 1 must still explore.

Produce `PM/PRD.md`. Advance only after explicit user approval.
