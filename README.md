# Johnny Project Team Plugin

這個儲存庫同時維護兩個**彼此獨立**的 Host 版本。請只進入您要使用或修改的版本目錄；兩者的 manifest、agents、skills、hooks、文件與版本紀錄都不共用。

| 版本 | 目錄 | 適用 Host | 說明文件 |
|---|---|---|---|
| Antigravity Edition | [`antigravity/`](antigravity/) | Google Antigravity | [Antigravity README](antigravity/README.md) |
| Codex Edition | [`codex/`](codex/) | OpenAI Codex | [Codex README](codex/README.md) |

不要將一個版本的 manifest、hook 或 agent profile 複製到另一個版本。安裝與貢獻方式請分別依各版本 README 操作。
